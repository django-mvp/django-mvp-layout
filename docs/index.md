django-mvp-layout arranges a Django page, or a box inside one, by a nine-letter layout code such as
`lHh LpR lff`: a header, two sidebars, the page and a footer. The sidebars open, close, collapse to
an icon rail and become drawers on a narrow layout.

## Requirements

- Python 3.12 or 3.13
- Django 5.2, 6.0 or 6.1

## Installation

```bash
pip install django-mvp-layout
```

[Installation](developer/installation.md) in the developer guide covers the settings.
