A layout without Cotton

This page's base template is plain Django: an element per area, with classes the stylesheet knows. Two template tags write the attributes that come from options.

  • {% templatetag openblock %} layout_attrs "hHh LpR fFf" {% templatetag closeblock %} on the root reads the layout code.
  • {% templatetag openblock %} sidebar_attrs "left" persist="nav" {% templatetag closeblock %} on each <aside> sets how it collapses, where it becomes a drawer and the state it was left in.
  • A button with data-mvpl-toggle="left" anywhere inside the layout opens and closes the left sidebar.

The sidebars, toggles and drawers behave exactly as they do on the pages built with components. Close the left sidebar and reload: it stays closed.
