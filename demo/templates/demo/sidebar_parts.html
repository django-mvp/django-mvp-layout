A sidebar with view stacks its content as a header, a body and a footer. Put the content in c-layout.header, c-layout.body and c-layout.footer: each lands in its own place whatever order it is written in, and one left out takes no space. An upper-case letter keeps that part in place while the sidebar scrolls. The navigation on this page is view="HbF".

Each example is an 18rem tall layout with a fixed sidebar. Scroll each sidebar to see which parts stay.
